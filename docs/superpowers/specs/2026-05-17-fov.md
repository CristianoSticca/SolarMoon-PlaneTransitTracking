# TransitSky — FOV Simulation Spec

## Goal

Provide a realistic and intuitive simulation of the final shot for astrophotographers planning aircraft transits in front of the Moon or Sun.

The simulator must answer:

- How large will the Moon/Sun appear?
- How large will the aircraft appear?
- Will the aircraft fit inside the frame?
- What will the final composition approximately look like?

The simulation should prioritize:
- visual usefulness
- realtime interaction
- mobile usability
- perceived realism

NOT scientific-grade rendering accuracy.

# FOV Calculation

Horizontal Field of View formula:

```math
FOV = 2 * atan(sensorWidth / (2 * focalLength))
```

Return:
- horizontal FOV
- vertical FOV

Units:
- degrees

---

# Celestial Body Rendering

## Moon/Sun Angular Diameter

Approximate constants:

```ts
MOON_ANGULAR_DIAMETER = 0.5 // degrees
SUN_ANGULAR_DIAMETER = 0.53 // degrees
```

---

# Pixel Conversion

Canvas width defines rendering scale.

Formula:

```math
pixels = canvasWidth * (angularSize / FOV)
```

Example:
- canvas width = 1200 px
- moon = 0.5°
- FOV = 3.4°

Result:
- moon ≈ 176 px

---

# Aircraft Angular Size

Approximation:

```math
angularSize = aircraftSize / distance
```

Units:
- radians

Convert to degrees afterward.

---

# Aircraft Positioning

Aircraft position must be represented relative to:
- Moon/Sun center
- camera framing

Input:
- angular offset
- trajectory angle

Convert to pixels:

```math
pixelOffset = (angularOffset / FOV) * canvasWidth
```

# Rendering Engine

## Recommended Stack

### Preferred
- HTML5 Canvas 2D

### Alternatives
- Konva.js
- PixiJS

Do NOT use:
- Three.js
- WebGL
- heavy rendering engines

Reason:
- unnecessary complexity
- battery usage
- mobile performance concerns

# Rendering Pipeline

## Step 1
Calculate FOV.

## Step 2
Determine Moon/Sun pixel size.

## Step 3
Determine aircraft apparent size.

## Step 4
Convert relative angular coordinates to pixel coordinates.

## Step 5
Render:
- background sky
- Moon/Sun
- aircraft silhouette
